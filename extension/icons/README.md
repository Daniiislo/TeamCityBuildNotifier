# Icons

These are placeholder SVG icons. Before building for production, convert them to PNG:

## Convert with ImageMagick or similar:
```bash
magick icon-16.svg icon-16.png
magick icon-48.svg icon-48.png
magick icon-128.svg icon-128.png
```

Or use an online converter like https://cloudconvert.com/svg-to-png

The SVG files work for development but PNG is recommended for production.
